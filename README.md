A 105-character out-of-office auto-reply written as if a neglected houseplant sent it: "Out of office. I've been in this corner since March: unwatered, unpaid, and still expected to look alive." `main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validates it against the competition gate (UTF-8, 1–120 characters, not only white space, a single line), and audits it against the published judge brief (plant voice, surprise, punch, tightness, originality) before writing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 -P -s main.py
```
